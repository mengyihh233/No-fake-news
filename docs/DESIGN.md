# Design / 设计 / デザイン

## English

This is a research desk for repeated investigation: a compact question form, quiet navigation, and a report readers can inspect. Charcoal identifies navigation; vermilion identifies the current action or selected node. Source reliability is never encoded as a decorative score.

The evidence map is an original HTML/SVG implementation informed by [diagram-design](https://github.com/cathrynlavery/diagram-design) and its [semantic style guide](https://github.com/cathrynlavery/diagram-design/blob/main/skills/diagram-design/references/style-guide.md). It retains real report IDs and recorded citation relations. Select a claim, then a node; the inspector reveals full text. A relationship table provides an alternative to the graph. UI changes do not alter source images.

Advanced source/account options use [progressive disclosure](https://www.nngroup.com/articles/progressive-disclosure/). Complete text counterparts follow [W3C guidance on complex images](https://www.w3.org/WAI/tutorials/images/complex/). These references inform the design; they do not imply a formal usability study or accessibility certification.

## 简体中文

面向重复使用的调查工作区：紧凑输入、安静导航和可复核报告。深灰用于导航，朱红只突出操作或当前节点，不用装饰分数表达来源可靠性。

证据图为原创 HTML/SVG 实现，参考上方 diagram-design 及其样式方法。保留报告真实编号与记录的引用关系；选择命题、点击节点查看全文，另有关系表。界面改动不修改来源截图。

高级来源/账户选项采用渐进披露，复杂图提供完整文字对应内容，参考上方 NN/G 与 W3C。未宣称进行正式用户研究或通过可访问性认证。

## 日本語

繰り返し使う調査デスクとして、簡潔な入力、静かなナビゲーション、検証できるレポートを配置します。チャコールは案内、朱色は操作・選択を示し、装飾的スコアで出典の信頼性を表しません。

証拠図は上記 diagram-design を参考にした独自の HTML/SVG 実装です。実際の ID と記録された引用関係を保持し、主張・ノードの選択で全文を表示します。関連表も用意し、出典画像は変更しません。

高度な情報源・認証設定は段階的に表示し、複雑な図には完全な対応テキストを提供します。上記 NN/G・W3C を参照していますが、正式なユーザー調査や認証は主張しません。
