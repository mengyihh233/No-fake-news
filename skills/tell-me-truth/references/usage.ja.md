# tell me truth — 詳しい使い方

ユーザーの論題を、出典と推論を追跡できる証拠レポートにします。証拠不足・矛盾・検証不能も有効な結果です。唯一の最終的な真実を保証しません。

## 入力・言語・モード・深さ

文章、ニュースの URL、質問、状況を受け付けます。指定された期間・地域・対象・出力言語を守ります。`zh-CN`・`en`・`ja` をサポートし、明示的な指定、会話の言語、`zh-CN` の順で選びます。レポートの `language` は本文の言語です。情報源の元タイトル、抜粋、正確な引用、検索語、URL、数値、日付、画像は原文を保持します。翻訳は明示した説明として追加し、原資料を上書きしたり言語によって証拠基準を変えたりしません。

既定は **資料を見て自分で判断**・**標準の深さ** です。現実の出来事と仮定の状況を区別し、仮定を確認済みの事実にしません。

- **evidence-only**：主張、原資料、時系列、データ・論理・歴史の比較分析を表示します。再計算できる数値、論証に必要な前提、共通条件、相違点、未解決の問いを説明します。真偽判定、誤謬のラベル、誘導的な要約、確率スコアは出さず、JSON や HTML の隠れたデータにも含めません。選択の偏り、調査範囲、不足を開示します。
- **ai-summary**：同じ証拠と共通分析に、主張ごとの判定と出典付きの論証を追加します。モード切り替え時は証拠を再利用し、必要な場合のみ再調査して変更を明記します。

入力が十分明確なら実行します。対象・日付・原文が不明で調査対象が変わる場合のみ確認します。それ以外は仮定を明記して進めます。

深さは判定の有無から独立しており、詳細モードを AI 要約に強制しません。

- **brief**：中心となる主張に絞り、中立的背景、支持資料、反証、当事者の過去記録の四方向を試み、必要な原資料・比較・不足を示します。
- **standard**：全手順を実行し、主要な主張、集計基準、歴史的な比較可能性を照合します。
- **deep**：独立資料と競合する説明を追加し、当事者の時系列と反対の結果になった比較事例を広げます。実データが十分なら換算と感度を確認します。資料の量で確実性を装いません。

時間・費用・ネット接続・ツールの制限を守り、実際の調査範囲を記載します。ウェブアプリには別途、検索数・資料数・時間の上限があります。公平性は一貫した基準と再検証できる選択で追求し、完全な無偏向を約束しません。

## 調査手順

1. **主張を分解する**：原文を保持し、事実・因果・予測・価値判断を分けます。C1…を付け、限定語・単位・期間・範囲・合理的な解釈を示します。価値判断に客観的な真偽ラベルは付けません。
2. **競合する検索を計画する**：中立的背景、最も強い支持、最も強い反証、当事者自身の過去の発言・データ・約束を探します。どの証拠で判定が変わるかを先に定め、ユーザーや特定の立場の誤りを前提にしません。
3. **原資料を取得する**：本セッションで実際に利用できるツールを使い、出典を開いて文脈を読みます。検索スニペット、モデルの記憶、生成回答を閲覧済みの原資料と扱いません。ツールや権限がなければ制約を説明して調査計画・未確認資料を渡し、調査済みと称しません。
4. **出典と系統を確認する**：所在の分かる元データ、原文書、完全なインタビュー、研究本文を優先し、発行者・方法・日付・改訂・利害関係を確認します。同じ原資料の転載は同じ証拠系統です。公式資料も検証対象であり、信頼性と主張への支持を分けて記録します。
5. **データ・論理・歴史を分析する**：[検証方法](methodology.ja.md)に従い、分母・単位・標本・期間・因果条件・比較可能性を確認します。発言の不一致だけで現在の主張を虚偽としません。類似点・相違点・交絡要因・推論の限界と、反対の結果の比較事例を示します。
6. **証拠のつながりを作る**：資料に E1…を付け、数値・時系列・歴史比較・公開論証を閲覧済み資料の ID に結びます。共通の `observations` には中立的なデータ・論理条件・歴史比較を入れ、判定と評価的な推論は要約専用の項目に入れます。抜粋・計算・仮定・不明点を区別します。公開するのは検証可能な前提と結論であり、モデルの内部思考ではありません。
7. **資料パッケージを作る**：[レポート形式](report-format.ja.md)に従い、実際の取得日時を記録します。所在の分かる実データのみグラフ化し、数値がなければ表や時系列を使います。見栄えのためにグラフ、資料、証拠数を捏造しません。

複雑な論題では、環境が対応する場合、支持・反証の独立調査や論証レビューを並行委任できます。系統ごとに重複を除き、多数決で真偽を決めません。

## v0.2：正確な引用・文書・追加検索

新規調査は schema `1.1` を使い、既存の `1.0` レポートも読めます。観察、時系列、歴史比較、グラフのデータ、任意の判定には `citations` として証拠 ID と逐語的な `quote` を付け、原文の言語・空白・改行を保持します。翻訳や言い換えを原文の代わりにしません。実際のツールで確認した位置情報には Unicode コードポイント区間 `[start, end)`、前後それぞれ最大 80 文字、抜粋の SHA-256、一致件数を含め、複数一致では最初の箇所を選びます。位置は**保存して表示した抜粋**内のもので、元ページの DOM や PDF のページ番号ではありません。`verification=exact_match` は文字の存在のみ、`semantic_support=unverified` は分析への意味的な裏付けが未検証であることを示します。引用・画像・ハッシュは真実性を認証しません。ホストが位置の確認や計算をできなければ不足を明記し、位置・指紋・検証済み表示を捏造しません。AI 要約の追加では既存資料を使い、読み込んだ出典を再取得・認証したと称しません。

PDF、HTML の表、CSV、TSV の読み取りは実際のホストツールに依存し、ウェブ版の抽出機能が Skill にもあるとは限りません。適切なツールがなければ未読または抽出失敗と記し、表・ページ番号・行列位置・画像を捏造しません。見出し・単位・脚注・空欄・読み順を確認し、切り詰め・結合セル・解析の制約を明示します。ウェブ版はテキスト PDF を抽出し、OCR やパスワード解除を提供しません。PDF の表は検証済みのセル復元ではありません。資源制限は[検証方法](methodology.ja.md)を参照してください。

追加検索は任意で、初期設定は `adaptive_search=false` です。判定モードとは独立しています。初回のウェブ調査は中立・支持・反証・当事者の履歴を検索します。有効にすると brief / standard / deep で最大 **1 / 2 / 2 件を追加**し、DeepSeek のモデル・検索呼出しなどで料金が増える場合があります。出典数・主張数・抜粋・総制限時間は増えません。指定情報源の優先と指定ドメインのみの制約は両ラウンドに適用します。取得枠がない、または残り 45 秒未満なら追加検索を省き、実際の制約を開示します。

`retrieval_gaps` は**初回**に抜粋のキーワード一致がない、または一致する出典グループが二つ未満という目安の記録です。`attempted` は検索を開始したことだけを示し、成功や不足解消を意味しません。成功した検索には `search_log` の `round` と `gap_claim_ids` を付け、追加検索の失敗は別途明記して初回資料を保持します。キーワードやグループ数は意味的な網羅性・完全性・真偽を証明しません。出典グループはドメイン、レスポンスのバイト列ハッシュ、十分に長い同一抜粋、長文の高い類似度によって暫定分類し、`source_family_method` と関連証拠 ID を示します。共通出典や独立性の証明ではないため、方法上の限界を説明します。

## スクリーンショットと提供

現在利用できる実際のブラウザー・PDF 撮影ツールを使います。関連箇所と十分な前後関係を撮影し、元 URL・タイトル・日時・未編集画像を保持します。切り抜き、OCR、翻訳、注釈は明記します。画像生成、再現ウェブページ、合成画像を出典画像の代わりにしません。

撮影に失敗した場合、URL、閲覧済み抜粋、位置、失敗理由を残して未取得と表示します。画像と SHA-256 は取得ファイルの確認を補助するだけで、主張の真実性を認証しません。

主張 → 出典 → データ・出来事・比較 → 分析と制約をクリックして追える形で渡します。有用なら利用可能な対話型可視化を使います。単独 HTML は Skill 内の標準ライブラリのスクリプトで作成します。

```text
python <skill-directory>/scripts/render_report.py report.json --output report.html --mode evidence-only --language ja
python <skill-directory>/scripts/render_report.py report.json --output report-summary.html --mode ai-summary --language ja
```

2 行目は確認済みの summary が既にある場合のみ使います。スクリプトは検索や判定を生成しません。`--language` はラベル・メッセージのみ変更し、本文を翻訳しません。ローカル画像の相対パスは JSON の場所を基準に解決し、実際の PNG・JPEG・WebP のみ埋め込みます。結果を確認してから渡します。

別のウェブアプリは OpenAI 互換 AI、Tavily・Brave 検索、任意の撮影を提供します。その権限・鍵・ブラウザー機能は Skill とは独立しており、全ホストで使えると仮定しません。ウェブのレポートを追加検証の入力にできます。

## 指定情報源とアカウントが必要なサイト

指定された情報源を受け付け、追加情報源として使う場合と指定範囲のみに限定する場合を区別します。ホストが設定保存に対応し、ユーザーが許可した場合のみ、秘密を含まないサイト一覧と範囲の設定を保存します。実際に保存せず永続記憶を約束しません。指定先、アクセス失敗、範囲の不足を開示します。限定した一覧はウェブ全体を網羅せず、内容の真実性も保証しません。

アカウントが必要なサイトは、ユーザーが許可し本セッションのツールが対応する場合のみ利用します。パスワード、Cookie、Bearer token、MFA コードを会話やレポートで求めたり再掲したりせず、ログインや MFA を回避しません。ホストの認可フローか専用入力を使い、対応ツールがなければ許可された秘密を含まない本文の提供とアクセス制約の説明を行います。取得本文を外部 AI に送る場合は事前に知らせます。

ウェブ版は指定情報源を最大 6 件受け付けます。Basic・Cookie・Bearer の認証情報は現在のメモリー内セッションだけに保持し、許可された正確な origin（方式・ホスト・ポート）に結びます。別 origin に送らず、レポートや検索記録に保存しません。認証を使う情報源は撮影しません。`source_policy` と `preferred_sources` は秘密を含まない範囲情報だけを保存します。

## 判定と訂正

要約モードでは、支持・反証・一部成立・文脈不足・証拠の矛盾・証拠不足・検証不能など、資料に見合う表現を使い、証拠と推論を付けます。校正されていない真実性の割合を出しません。「見つからない」と「存在しないと証明された」を区別します。

開けるレポートと出典を、範囲・基準日・未解決の問い・判定を変え得る資料とともに提供します。訂正時は旧版を残し、新ファイルに変更と理由を記します。他の AI の制限回避や偏りの完全な除去を約束しません。

位置を確定的に計算できない独立 Skill は、原文と制約を保持した `1.0` を使います。`1.1` は再現可能な完全な位置情報を必要とし、モデルの推測で埋めてはいけません。
