# tell me truth

把用户的论题转为可复核的证据报告。目标是让读者追溯证据及推论，允许证据不足、冲突或无法核查；不保证得到唯一真相。

## 输入与模式

接受文本、新闻链接、具体问题或情景。沿用用户指定的时间、地域、对象和输出语言；没有指定时用中文，默认 **列出信息自行判断、标准深度**。明确是现实事件还是假设情景；假设本身不得写成已发生事实。

- **列出信息自行判断**：展示论断、原始资料、时间线及数据、逻辑、历史的比对分析。客观分析说明数字怎样计算、论证成立需要什么前提、历史案例有哪些相同条件与差异；保留待解问题。省略真假裁决、谬误标签、倾向性总结及概率分数；不把这些内容藏在导出文件或 HTML 的数据里。来源选择仍可能有偏差，要披露搜索范围与缺口。
- **AI 生成总结**：在同一证据集上增加逐命题判断、可复核的论证与局限。后续切换此模式时，先复用证据；过时才重查并标明变更。

输入足够明确就执行。只有无法确定关键主体、日期或原话且会改变查证对象时，询问必要问题；其余缺口用明确假设继续。

**分析深度独立于是否判断**，不要把深入模式强制切成 AI 总结：

- **简要 brief**：聚焦核心命题，覆盖中性背景、支持、反证和主体历史四个方向，给最必要的原始资料、比对及缺口。
- **标准 standard**：完整执行下述流程，交叉核对关键命题、数据口径和历史可比性。
- **深入 deep**：增加独立来源与竞争解释，扩展主体时序及结果相反的可比案例；有足够真实数值时复核换算和敏感性。深入仍允许无法判断，不用材料数量伪装确定性。

尊重用户的时间、费用和工具预算；在报告注明实际检索边界。网页应用另有明确的各档查询/来源/时限上限。客观公正通过同一证据标准、透明取舍和可复核分析来追求，不承诺绝对无偏。

## 查证过程

1. **拆命题**：保留原话，把事实、因果、预测、价值判断分开。给可核查命题分配 C1、C2…，明确限定词、单位、时间范围及可能的合理解释。价值判断没有客观真假标签。
2. **制定竞争检索**：分别搜索中性背景、最强支持、最强反证、相关主体自身的历史原话/数据/承诺。先定义什么证据会改变判断。避免把任务自动解释为证明用户或某方错误。
3. **检索并阅读原件**：使用本轮实际可用的联网工具；打开来源确认上下文。搜索摘要、模型记忆、自动生成回答不能冒充读过全文。工具不可用就说明限制，交付查证方案或待核实材料，不生成“已经查证”的报告。
4. **审核来源与谱系**：优先可定位的原始数据、原始文件、完整采访和研究正文；核对发布者、方法、日期、修订及利益关系。多家转引同一原件视为同一证据谱系。官方来源同样需要核查。来源可靠程度与它是否支持命题分开记录。
5. **分析数据、逻辑和历史**：按 [核查方法](methodology.md) 核对分母、单位、样本、时段、因果条件及可比性。检查涉及主体的前后记录；前后不一致不自动证明当前说法为假。历史类比列出相似点、关键差异、混杂因素和可推论边界；也寻找结果相反的可比事件。
6. **建立证据链**：每份材料赋 E1、E2…；每个数据点、时间线事件、历史比较和公开论证都链接到已读取的证据 ID。两模式共享的 `observations` 记录数据、逻辑前提、历史可比性分析；真假判断及评判性推论只进入 AI 总结字段。把事实摘录、计算、分析中的假设与未知项区分。论证链是读者可检验的前提与结论，不是模型内部思维记录。
7. **形成材料包**：按 [报告结构](report-format.md) 写入 JSON，使用实际检索时间。图表只采用可定位的真实数据；没有数值就用表格或时间线。不要补造图表、资料或证据数量来凑版式。

对于复杂论题，在环境允许时并行委派相互独立的支持证据检索、反证检索或论证审查；汇总时按来源谱系去重，不能按投票得出结论。

## 网页证据和展示

需要网页截图时使用当前环境真实的浏览器或 PDF 截图工具。捕获与证据对应的段落，并保留原 URL、标题、采集时间、未修改的原图；裁剪、OCR、翻译或标注须说明。不得用图像生成、网页仿制或拼图替代来源截图。

截图失败时保留原网址、已读摘录、定位和失败原因，清楚标为未取得截图。不得宣称完成截图。截图和 SHA-256 仅辅助复核采集文件，不认证页面说法为真。

把报告交付为可点击的“命题 → 来源 → 数据/事件/比较 → 论证及局限”链。交互展示可使用当前可用的可视化能力。需要可携带 HTML 时，执行本 Skill 内的标准库脚本：

```text
python <skill-directory>/scripts/render_report.py report.json --output report.html --mode evidence-only --language zh-CN
python <skill-directory>/scripts/render_report.py report.json --output report-summary.html --mode ai-summary --language zh-CN
```

第二条仅在报告已包含经核查的 AI 总结时使用；脚本只渲染，不联网、不生成模型结论。截图本地路径相对 JSON 文件解析并内嵌；只接受真实 PNG/JPEG/WebP。查看结果后再交付。

独立网页项目 `tell-me-truth` 另提供 OpenAI 兼容 API、Tavily/Brave 搜索及可选网页截图。它与本 Skill 的工具权限、密钥及浏览器能力各自独立；不能假设任意宿主都有相同工具。网页生成的报告可作为本 Skill 的输入继续核查。

## 结论及交付

AI 总结模式使用与证据匹配的描述，例如支持、反驳、部分成立、关键语境缺失、证据冲突、证据不足或不可核查。所有判断附证据及推论依据；不输出未经校准的“真实性百分比”。区分“尚未查到”与“已证明不存在”。

交付可打开的报告及来源，简述范围、截止时间、未解决问题和可能改变判断的新证据。更正时保留旧报告，以新文件注明修改及原因。不要用报告模式承诺绕过其他 AI 的限制，也不要承诺完全消除立场影响。

## 语言、指定来源与账户网站

支持完整简体中文 `zh-CN`、English `en`、日本語 `ja`。用户明确选择优先；否则沿用对话语言，无法判断时用 zh-CN。报告 `language` 表示正文语言。原始标题、引用、摘录、查询词、数据、日期、精确计算引句和截图保留原文；需要翻译时另加明确标识的解释，不覆盖原件。不因语言切换改变证据或判断标准。渲染器 `--language` 只切换标签和提示，不翻译报告正文。

接受用户指定的常用来源列表，并区分“补充来源”和“仅在指定来源内研究”。如宿主支持保存偏好且用户授权，可保存非秘密的网站列表及范围偏好；未实际保存时不得承诺永久记忆。报告披露指定来源、实际访问范围、失败和缺口；仅指定来源模式不能声称穷尽全网，也不保证指定来源真实。

账户网站仅在用户授权且本轮工具支持时访问。不要在对话或报告中索取、复述或输出密码、Cookie、Bearer token、MFA 码等秘密，不绕过登录或 MFA。使用宿主的授权流程或专用凭据输入；没有合适工具就让用户通过允许方式提供非秘密原文，说明访问限制。网站正文若将发送给外部 AI 服务，用户须事先知情。

网页版本最多接受 6 个指定来源；Basic、Cookie、Bearer 凭据仅用于当前内存会话，精确绑定授权的 origin（协议、主机、端口），不发送给其他 origin、不保存到报告或搜索日志。需要账户授权的来源不采集截图。`source_policy` 和 `preferred_sources` 仅保存非秘密范围信息，不能容纳凭据。
